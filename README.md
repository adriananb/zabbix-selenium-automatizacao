# 🤖 Automação de Cadastro no Zabbix 7.4 com Python & Selenium

Este repositório contém scripts de automação Web desenvolvidos em Python utilizando Selenium WebDriver para interação e cadastro automatizado de hosts no painel de monitoramento Zabbix 7.4.

## 🚀 Funcionalidades

- **`automacao_zabbix.py`**: Efetua o login automático e cadastra um host individual preenchendo grupo e interface de rede.
- **`cadastrar_multiplos_hosts.py`**: Automação em lote que realiza o cadastro sequencial de múltiplos servidores (utilizando dicionários Python e loops de repetição).

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Selenium WebDriver**
- **WebDriver Manager** (gerenciamento automático do ChromeDriver)
- **Zabbix 7.4**
